# Documentos

Aquí van los PDF que se descargan desde la web: las fichas de inscripción, la
autorización de derechos de imagen y lo que haga falta.

Se suben desde el panel, en la sección **Inscripciones** de la portada: cada
ficha tiene un campo «PDF». Al subirlo, la ficha pasa de «Próximamente» a ser
un enlace de descarga.

También se pueden dejar aquí a mano y apuntarlos en
`datos/portada.json`, en el campo `archivo` de la ficha, así:

    "archivo": "documentos/ficha-inscripcion-cadete.pdf"

Este README no se publica: el workflow lo descarta al empaquetar.
